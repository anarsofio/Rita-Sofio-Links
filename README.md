# Rita Sofio — Links

Link-in-bio page for Rita Sofio / DigitalMindsStudio, built with TanStack Start, React and Tailwind.

## Edit the cards

The cards live in the `LINKS` list in `src/routes/index.tsx`. Change a title, description or `href`, add or remove an entry, or re-order the list — the layout adjusts itself from each card's `size`.

Social icons and the main website address are in `src/components/site/site-links.ts`.

## Run it

```bash
bun install
bun run dev      # local dev server
bun run build    # production build
bun run test     # unit tests
```
